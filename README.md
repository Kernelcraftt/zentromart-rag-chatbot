# ZentroMart RAG Chatbot

A Retrieval-Augmented Generation (RAG) based AI customer support assistant built using FAISS, Sentence Transformers, and OpenRouter LLM.

## Features

- Retrieval-Augmented Generation (RAG)
- Semantic search using FAISS
- Document chunking with LangChain
- SentenceTransformer embeddings
- OpenRouter LLM integration
- Order lookup with customer verification
- Rule-based intent classification
- Customer support knowledge base

## Tech Stack

- Python
- OpenAI API (OpenRouter)
- FAISS
- Sentence Transformers
- LangChain
- Pandas
- NumPy

## Project Workflow

1. Load knowledge base documents
2. Split documents into chunks
3. Generate embeddings
4. Store embeddings in FAISS
5. Retrieve relevant context
6. Generate responses using OpenRouter
7. Handle order lookup and support queries

## Example Queries

- Can I return my laptop after 8 days?
- How long does a refund take?
- Who pays the reverse pickup fee?
- Where is my order 69520867?
